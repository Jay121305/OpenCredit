2. Quick Test Flow

Follow these steps to see the main features (Fraud Detection & Ledger) in action:

Step 1: Sign In

Go to the main Sign In page and use the Admin credentials to log in. This gives you full access to all tabs.

Step 2: Create a Merchant

Navigate to the Merchants tab and create a new merchant. The system will give you a mock API Key.

Step 3: Process a Payment

Go to the Payments tab. Enter an amount (e.g., $100) and process a test payment. It should be approved automatically.

Step 4: Trigger the Fraud Engine

To see the ML Fraud Detection at work, try processing a payment of $6,000. Because the default threshold is $5,000, the system will flag/reject it.

Step 5: Check the Immutable Ledger

Go to the Ledger tab. Here you will see the cryptographic hash-chain representing your transactions. Click Verify Chain to ensure data integrity.

3. What Does What? (System Components)

  • Authentication & Roles: Managed via JWT tokens. Different roles see different data and have varying permissions.
  • Fraud Detection: Uses a Machine Learning Isolation Forest model plus rule-based checks (High Value, Transaction Velocity, Geo-Mismatch).
  • Ledger System: A blockchain-style immutable audit trail. Any tampered transaction will instantly break the hash chain validation.
  • RBAC (Role-Based Access Control): Viewers can only view the dashboard, Users can perform payments, Analysts can view aggregated records, and Admins control everything.
