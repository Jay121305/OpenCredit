🔐 Authentication

1. Register a User

Create your first account using the API:

POST /api/v1/auth/register
Content-Type: application/json

{
  "email": "admin@example.com",
  "password": "SecurePass123!",
  "full_name": "Admin User"
}

2. Login

Get your JWT access token:

POST /api/v1/auth/login
Content-Type: application/json

{
  "email": "admin@example.com",
  "password": "SecurePass123!"
}

3. Use the Token

Include the token in all authenticated requests:

Authorization: Bearer YOUR_JWT_TOKEN
💡 Tip: Go to /docs and click "Authorize" to log in with your token. You can then test all endpoints interactively!

📋 API Endpoints

Authentication & Users

  • POST /api/v1/auth/register - Register new user
  • POST /api/v1/auth/login - Login and get JWT token
  • GET /api/v1/auth/me - Get current user profile
  • GET /api/v1/users - List users (admin only)

Financial Records

  • POST /api/v1/records - Create financial record (analyst+)
  • GET /api/v1/records - List records with filters (viewer+)
  • PUT /api/v1/records/{id} - Update record (analyst+)
  • DELETE /api/v1/records/{id} - Soft delete record (analyst+)

Dashboard & Analytics

  • GET /api/v1/dashboard/summary - Financial summary (viewer+)
  • GET /api/v1/dashboard/categories - Category breakdown (analyst+)
  • GET /api/v1/dashboard/trends - Time-series trends (analyst+)

Payments & Fraud Detection

  • POST /api/v1/payments - Process payment with fraud check
  • GET /api/v1/payments/{id} - Get payment details
  • GET /api/v1/analytics/fraud-stats - Fraud statistics

Ledger (Blockchain-style)

  • GET /api/v1/ledger - Get ledger entries (viewer+)
  • GET /api/v1/ledger/verify - Verify ledger integrity (analyst+)

🔑 User Roles

The system has 4 hierarchical roles:

  1. Viewer - Read-only dashboard access
  2. User - Standard user (default)
  3. Analyst - Create/edit records + analytics
  4. Admin - Full administrative access
⚠️ Note: New users are created with "user" role by default. Use the admin endpoints to change roles.

🧪 Testing the API

Method 1: Swagger UI (Easiest)

  1. Go to /docs
  2. Click "Authorize" button (top right)
  3. Register/Login to get a token
  4. Paste token and click "Authorize"
  5. Test endpoints by clicking "Try it out"

Method 2: cURL

# Register
curl -X POST /api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"Test123!","full_name":"Test User"}'

# Login
curl -X POST /api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"Test123!"}'

# Get dashboard (with token)
curl /api/v1/dashboard/summary \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

Method 3: Postman/Insomnia

Import the OpenAPI schema from /docs or manually add endpoints.

⚙️ Configuration

Environment variables are set in Render Dashboard → Environment:

  • DATABASE_URL - PostgreSQL connection string
  • JWT_SECRET - Secret key for JWT tokens
  • ENV=production - Environment mode
  • RESEND_API_KEY - (Optional) Email service
  • REDIS_URL - (Optional) For analytics worker
